04 / technical stackSentimentIQ Architecture
Frontend-first delivery

The architecture is intentionally lightweight.

Shell
React 19 + ViteModern application core and production-ready build pipeline.
Interface
Tailwind 4 + WouterResponsive utility styling and lightweight client-side routing.
Analytics
Recharts + VADERDeclarative data visualization and lexicon-based sentiment comparison.
Ingestion
Papa Parse + PDF.jsBrowser-side extraction for CSV, DOCX, and PDF documents.

Current scope: Frontend-only

The application operates entirely in the browser. Identity, reviews, and presets are stored in localStorage and IndexedDB.

No authoritative server database or application API is currently active.
